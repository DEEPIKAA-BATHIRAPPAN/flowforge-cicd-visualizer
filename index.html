Example workflow

Illustrative YAML — not executed by this visualizer.

YAML
# Example CI/CD workflow
name: Build, test and deploy
on: [push, pull_request]

jobs:
  build:
    steps:
      - Checkout source
      - Install dependencies
      - Build application

  test:
    needs: build
    steps:
      - Run unit tests
      - Check code quality

  staging:
    needs: test
    steps:
      - Deploy preview build
      - Run smoke tests

  production:
    needs: staging
    environment: production (approval required)
    steps:
      - Wait for manual approval
      - Deploy release
ⓘ   Demo configuration

This is an example only. Later, adapt it to GitHub Actions, GitLab CI, or Bitbucket Pipelines.
